# Petxercise

Prototipo de una app para organizar los paseos de perros: la semana de actividades, el paseador asignado, el paseo en vivo, el álbum de fotos y el perfil del perro.

Construido por Ana con ayuda de IA para validar la idea antes de invertir en desarrollo.

## Cómo verlo

Abre `index.html` en cualquier navegador. No necesita instalar nada.
